## Encoding intervention

An external wrapper around the actual native `Tokenizer.encode` runs before it returns input IDs to context validation and generation/cache bookkeeping. It intercepts only the exact rendered-prompt SHA. The user message must appear once at its original byte-preserved span. Actual native CPU IDs must equal the original verified348-token array. Using the same tokenizer's model/merges/normalizer/pre-tokenizer/decoder, with only the companion added-token matcher table disabled, it expands the two native marker IDs wholly inside that user span. All other original token IDs remain unchanged, including every structural template control. The returned CPU long tensor contains352 IDs. Both arrays decode to the identical full rendered prompt.

This intervention is explicit: observer config requires `diagnostic_user_bpe: true` and `input_tokenizer_json` pointing to the exact audited3.05 tokenizer JSON (SHA0997f410c57a1f4e53b09e4be8f4a172d90edd9564368fb0847030937229b9f3). Context validation before the collector is active is intentionally intercepted too. Active request encoding produces per-request proof. Nonmatching strings, including the reasoning cutoff injection and template-only strings, use the original encoder. For the matched synthetic prompt, unsupported BOS/EOS/offset/batch/multimodal settings, simultaneous matching requests, native ID drift or excess encoding calls fail closed. Config is fixed and hashed by the lifecycle wrapper; this is not a generic unknown-key schema validator.

Each raw record gains `input_tokenization` with original/changed IDs, their hashes, counts, user/marker spans, and preservation declarations, plus `input_encoding_calls` from actual native encode calls. The pure `validate_input_tokenization(trace)` checks those complete arrays/hashes, reconstructs the exact two expansions, verifies all other input IDs are unchanged, and requires native reported prompt usage352. The lifecycle independently requires API prompt usage352. Cached-token counts remain actual observations, not assumed zero.
